
## Running the Project

 > **Prerequisite:** Install [Go](https://go.dev/doc/install) (version 1.18 or higher). Follow the official installation guide for your operating system before proceeding.

1. Clone the repository:
    ```bash
    cd GoTogether-backend/api-service
    ```

2. Install dependencies and run the service:
    ```bash
    go mod tidy
    go run main.go

3. The API service will start on the configured port. Check the terminal output for details.

4. To stop the service, press `Ctrl+C` in the terminal.
